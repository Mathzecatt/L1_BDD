VCub Back-Office

Application console qui gère les stations et les abonnements du vélo en libre-service bordelais, sur une base PostgreSQL. Session enregistrée avec asciinema et rejouée dans votre navigateur : le texte est sélectionnable.

  • PostgreSQL 16
  • Python 3
  • psycopg2
  • requêtes paramétrées
